# Shared planning pages

Mode: Operate for owner controls; Read for guests. Ordinary extension of the selected sharing preview and persisted workspace. Code-first; no new identity, imagery, or dependencies. Personal reference catalog has no saved entries. Public sharing controls are owner-only, confirmed by the user.

## Direction contract

THESIS: Share a deliberate selection, never a miniature private dashboard. A clear publication boundary separates saving choices from opening public access.

OWN-WORLD: Inherit cream paper, forest actions, serif event names, sans-serif controls, thin rules, and the existing invitation composition. Owners work in EventLayout; guests see no workspace shell.

STORY: Choose details, preview saved content, publish, copy a link, and revoke it. Optional summaries stay off until explicitly selected. Anyone holding the link can read it; no account or editing access is granted.

FIRST VIEWPORT: Owner page starts with publication status and link actions, followed by labeled inclusion choices. Guest page leads with the event name and selected date/location; the public note and opt-in sections follow as a restrained single-column reading page. Phone controls stack without clipping.

FORM: Ordinary extension of the user-selected sharing preview, no seed. Signature interaction: save choices and open the exact server-filtered guest preview before publishing. Pending and successful actions remain explicit; short existing transitions respect reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
