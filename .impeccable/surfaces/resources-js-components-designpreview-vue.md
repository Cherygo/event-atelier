# Workspace redesign

Mode: Operate. Scope: public interactive sample, not production event CRUD. Preserve overview, tasks, vendor comparison, budget, and shared-page preview; laptop and mobile.

## Direction contract

THESIS: Bring the next task and next decision forward, using the editorial identity without making planning work feel like a marketing page.

OWN-WORLD: Forest sidebar and event banner, cream working canvas, clear ruled task lists, consistent outline icons, readable sans-serif controls, restrained serif event names.

STORY: Switch between independent wedding and corporate examples; complete or add a task; compare vendors; inspect spending; control a read-only sharing preview.

FIRST VIEWPORT: Narrow green sidebar, clear sample-data notice, title and actions, compact photographic event banner, task and budget summaries, and the actual next tasks. On phones, a disclosure navigation and single-column task-first flow replace the sidebar.

FORM: User-selected Editorial–Estate combination, explicitly confirmed. No seed for the pinned direction. Signature interaction: task completion updates the same event's checklist summary immediately and preserves the other sample's state.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
